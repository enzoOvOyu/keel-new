# BOM AI 映射评测集模板

本目录用于收集经过脱敏的真实开局表与人工核验标准答案。当前不包含任何真实客户文件，也不声称存在已测得的识别准确率。

## 目录约定

```text
bom-evaluation/
  README.md
  manifest.csv              # 每个样本的元数据
  field-gold-template.csv   # 人工标注的字段标准答案模板
  relation-gold-template.csv# 人工标注的实体关系标准答案模板
  samples/                  # 脱敏 Excel，仅经授权后加入；默认不提交 Git
```

## 采样要求
- 覆盖不同实施人员、模板、Sheet、表头风格、列顺序、合并单元格、多行表头和异常案例。
- 训练/调优集与独立验收集分离；同一原始工作簿的近似副本不得跨集合泄漏。
- 标准答案由网络领域专家核验，记录标注人、审核人和版本。
- 脱敏 SN、MAC、IP、项目名、客户名、凭据引用和拓扑标识；若保留关系一致性，使用可重复映射的假值。
- 禁止提交明文密码、token、私钥或未授权客户文件。

## 指标
分别报告字段级 precision/recall、关键字段准确率、关键关系准确率、BLOCK 漏检率、人工修改比例、每份文件人工耗时、解析失败率和端到端产物正确率。按字段风险分层报告，不以总体平均值掩盖关键字段错误。

置信度只能用于排序和辅助审核，不能单独决定关键字段自动放行。评测报告必须写明样本量、数据划分、模型/提示版本、映射规则版本和实际运行日期。
