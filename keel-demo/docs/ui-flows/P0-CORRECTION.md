## 四个代表页面线框

Dashboard
```
项目 / 交付范围 / 数据时间
交付阶段轨道（网络阶段 → G1…G6 → 退场），点击进入证据
关键阻断队列                         当前执行及失败目标
机柜健康矩阵（16柜，按真实资产聚合）     资源规模 / 新鲜度
```

BOM
```
导入任务目录 → 导入任务详情（独立路由）
阶段导航：上传 → 解析 → 映射 → 校验审核 → 预览 → 提交
Sheet导航 | 源单元格/原值 | 目标字段/修正值/理由/确认
底部问题清单：定位到源单元格；未知列、歧义、敏感字段分别处理
固定摘要：批次/hash/版本/阻断/未确认WARN；服务层再次校验提交
```

机柜图
```
机柜导航 | SVG主画布（前/后，多柜） | 设备/端口/线缆详情
缩放/平移/拖放预览；移动只修改草稿；方向键/撤销/重做
问题清单 + 未分配设备 + 版本diff → 生成新revision → 发布 → 导出
```

Flow / Execution
```
Flow目录 → 编辑器（脚本、目标、参数、策略、调度）
目标筛选/勾选 → 冻结目标与参数预览 → 模拟运行
执行独立详情：状态/开始结束/耗时/目标计数/操作
Overview/Gantt | Topology | Targets | Logs | Outputs | 关联
推进固定状态 → 部分失败 → 只重试失败目标；未知结果先核对
```

## 验收原则
先记录实际操作证据。路由能打开不是业务验收通过；未检查项保持 NOT RUN。
