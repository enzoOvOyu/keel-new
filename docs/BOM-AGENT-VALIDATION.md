## 已修正的直接问题

- 旧方案把 Cable Type 作为 speed、U Position 作为机柜高度、Customer Rack Name 作为 site，或用落位别名替代明确设备标签。显式表头语义现在校正对应来源绑定，别名保留，缺失值保持空。
- 同一物料表重复提取为多份相互重叠的对象；现在检查重叠来源。按真实类型列划分的互斥区域可以独立提取，未匹配内容仍保留。
- 每行重复保存长公式导致 workbench JSONB 超限；公式原文只在不可变 IR 中保存，按需查询，候选保留坐标及缓存标记。
- 仅显示抽象“识别完成”且无法区分漏提取；现在按区域列出扫描、字段提取、未映射、保留和人工处理情况。
- 页面固定模式与 AI 混杂、步骤缺少衔接；当前上传、真实进度、分类审核和确认入库分别呈现，交换机端口与双端连接可在同一详情面板查看。

## 未验证与边界

- complete 仅表示区域扫描及来源保留对账完成，不等于提取率 100%、实体正确率 100% 或正式入库许可。
- 未识别内容、缺少型号审批/所属实体/端点/规格/单位的候选继续待核查，不能通过 AI 置信度放行。
- 未建立经过人工确认的完整金标集；交换机属性/端口/线序准确率尚未测定，不使用 Agent 自报作为准确率。
- 任意图形/颜色或自由文本隐含关系、区域视觉识别、LibreOffice 公式重算、CSV/PDF/XLS 不在本轮已实现能力中。无法可靠结构化的原始内容保留。
- 批量人工审核、最终事务提交、重复提交与跨模块消费的完整业务验收由用户进行；本轮没有重跑历史端到端报告。
