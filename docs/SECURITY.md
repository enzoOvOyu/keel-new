# SECURITY.md — 安全与权限实施约束

## 1. 基本原则
- 默认拒绝；所有资源操作都在服务端鉴权，前端隐藏按钮不是安全控制。
- 权限范围为“模块 × 动作 × 项目资源范围”。每个查询、修改、导出、SSE/WebSocket 订阅、文件下载和后台任务执行都必须检查项目授权。
- 秘密值只存 Vault/Secret Manager；数据库、日志、审计正文、错误响应、浏览器存储和导出仅保存安全引用或脱敏值。
- 生产网络操作必须经过校验、备份、审批、执行、复采与审计；AI 不可审批或执行生产变更。

## 2. 身份与会话
- 按 PRD FR-10.1 实现本地账号/OIDC/LDAP 中实际启用的方式；不得提供未实现的登录入口。
- 浏览器会话使用服务端会话与 HttpOnly/Secure/SameSite Cookie；写请求验证 CSRF token 与 Origin。会话令牌不得放入 localStorage。
- OIDC 使用 Authorization Code + PKCE，并验证 state/nonce、issuer、audience 和严格白名单回调 URI。
- 登录错误不透露账号是否存在；限流与锁定参数以 PRD/参数目录为准。
- 账号禁用、角色撤销后既有会话与订阅立即失效。

## 3. RBAC 与审批
- 服务端对每次请求重新确认用户、项目、动作和资源范围。
- 高危动作执行前冻结项目、目标 UID/SN、动作、参数/模板版本及审批引用；执行时重新校验权限、门禁和目标快照。
- 普通网络变更按 PRD 由 NE+DE 双签；Critical 变更追加 NH 三签。审批绑定精确计划版本，修改计划后必须重新审批。
- `WAIVED` 必须记录授权人、范围、原因、有效期和证据；不得改写成 PASS。
- 后台任务在执行时重新验证发起人的授权策略与审批状态，不能只信任创建时的前端参数。

## 4. 凭据与敏感数据
- BOM/导入包只允许 `credential_batch_ref`、Vault path 等引用，不允许明文密码、私钥、token。
- 交换机、BMC、OS、AI provider 凭据采用用途隔离、最小权限、轮换和访问审计。
- 日志必须过滤 Authorization、Cookie、密码、API key、私钥、敏感环境变量和设备凭据。
- AI 请求只发送完成映射所需的最少上下文；优先发送字段/少量样例，不默认上传整份工作簿。项目级策略决定是否允许外部模型。
- 记录模型供应商、模型版本/配置标识、提示模板版本、输入摘要和输出审核结果；避免将完整敏感提示或原始表格写入普通日志。

## 5. 文件导入安全
- 白名单接受 PRD 规定的文件类型；验证扩展名、MIME、文件签名、大小、工作表/行列上限及压缩包解压后大小。
- XLSX/XLSM 宏不执行；不访问外部链接；公式不在服务端执行。公式缓存值缺失时标 unknown 并提示审核。
- 压缩包拒绝路径穿越、绝对路径、符号链接、重复路径、超限解压和压缩炸弹。
- 文件名仅作显示信息；对象存储 key 由服务端生成。下载与预览都鉴权。
- 原始文件不可变保存，计算 SHA-256；派生数据与原始文件分开保存并建立追溯关系。

## 6. API 与浏览器安全
- 所有写请求鉴权、授权、CSRF/Origin 检查、输入验证和审计。
- 限制上传/请求体大小、分页上限、导出范围、并发和速率；防止批量查询越权与资源耗尽。
- 防止 SQL 注入、命令注入、SSRF、路径穿越和不安全反序列化；数据库使用参数化查询。
- CORS 仅允许明确配置的可信来源，不使用生产环境通配符搭配凭据。
- Webhook 入站验证签名/时间戳/重放；出站目标使用白名单并防止访问内网敏感地址。
- OpenAPI 文档不得包含真实 token、真实客户地址或生产凭据。

## 7. 审计与事件
- 审计至少记录 actor、project、action、resource/version、request_id、时间、结果、审批引用和安全的前后值摘要。
- 审计采用追加写权限隔离；重要归档按部署策略进行防篡改保存与恢复演练。
- 审计不得保存秘密值；对原始文件、映射、修正、BOM 提交、模板发布、规则变更、生产下发、审批、导出和凭据轮换记录事件。

## 8. 安全验收最低项
- 用户 A 无法读取/修改用户 B 无权访问的项目数据，包括下载 URL、异步 Job、SSE/WebSocket 和导出。
- 未授权角色无法提交 BOM、批准模板、批准/下发网络变更或豁免门禁。
- 上传恶意/超限/路径穿越文件被拒绝；AI 服务不可用不会绕过审核或规则校验。
- 日志、错误、审计和导出中不存在明文秘密。
- 断连或超时导致副作用结果不明时进入对账状态，不盲目重放。

## 7. 开局 Excel 特别约束

- `TX B300 Layout-new.xlsx` 含有设备网络资料，并出现账户/密码列与明文凭据样例。该文件仅作受控解析样本，不得复制进文档包、Git、mock fixture、日志、审计正文或外部 AI 请求。
- 解析器对列名/表区做敏感信息分类；密码、token、私钥、共享密钥永不映射到 `bom_item` 普通字段。只允许映射为受控 Vault/credential batch 引用；若原表只提供明文密码，应阻断秘密导入并提示通过受控凭据流程录入。
- 发给 LLM 的上下文只包括必要表头、去敏后的样例值和有限邻接信息；任何敏感列先剔除/遮盖。模型供应商数据处理策略未确认前，默认不将原始工作簿内容发送到外部模型。
- mock 使用合成数据，设备名/IP/SN 可采用保留测试值；不复制真实生产凭据和真实资产标识。
## 机柜图与导出安全
- 机柜图标签、详情、搜索索引、CMDB 时间线、Mock fixture 和导出文件禁止包含密码、Token、私钥或未经授权的凭据字段。
- 原始 Excel 的访问权限与机柜图读权限分离；机柜图仅读取标准化且已授权的资产/端口/线缆字段。导出按项目 RBAC 授权并审计。
